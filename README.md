# 📚 Library Management System  

A **Library Management System** built with **Flutter** for the frontend and **MongoDB** as the backend database.  
The project supports two roles: **User** and **Librarian (Admin)**, with different permissions.  

---

## 🚀 Features  

### 👤 User  
- Borrow a book  
- Search for books by text or filter by published year  
- View book details  
- Check personal borrow history  

### 🛠️ Librarian (Admin)  
- View statistical information about books in the library  
- Search for books by text or filter by published year  
- View book details  
- Check borrow history of all users  

---

## 🏗️ Tech Stack  
- **Frontend:** Flutter (cross-platform mobile app)  
- **Backend Database:** MongoDB
